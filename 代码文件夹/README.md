# 闲鱼网站克隆

这是一个模仿闲鱼网站的前端界面项目，包含了闲鱼的主要视觉元素和交互功能。

## 项目结构

```
xianyu/
├── index.html          # 首页
├── detail.html         # 商品详情页
├── css/
│   ├── style.css       # 通用样式
│   └── detail.css      # 详情页样式
├── js/
│   ├── script.js       # 首页脚本
│   └── detail.js       # 详情页脚本
└── README.md           # 项目说明
```

## 功能特点

- 响应式设计，适配不同屏幕尺寸
- 闲鱼风格的黄色主题和UI元素
- 首页包含轮播图、分类导航、商品列表等
- 商品详情页包含图片展示、卖家信息、商品描述等
- 基本的交互功能，如点赞、收藏、图片切换等

## 如何运行

1. 直接在浏览器中打开 `index.html` 文件即可查看首页
2. 点击商品卡片可以跳转到商品详情页（detail.html）
3. 所有功能都是前端模拟，没有后端服务

## 技术栈

- HTML5
- CSS3 (使用Flexbox和Grid布局)
- 原生JavaScript
- Font Awesome 图标库

## 注意事项

- 这是一个纯前端项目，仅用于展示闲鱼的UI设计和交互
- 所有商品数据都是模拟数据，不是真实的商品信息
- 图片使用了占位符，实际项目中需要替换为真实图片
